# Fitness Calorie & Intensity Tracker

A clean, lightweight web-based application designed to help users log workouts, monitor intensity, estimate calorie expenditure, and calculate Body Mass Index (BMI) in real time.

## Features
* **Workout & Calorie Logging:** Track individual physical activities along with workout durations and estimated calorie burn.
* **Intensity Monitoring:** View and analyze workout intensity across logged sessions.
* **Built-in BMI Calculator:** Instantly compute Body Mass Index based on user height (cm) and weight (kg) inputs.
* **Dynamic Table Rendering:** Automatically updates and displays activity history in an intuitive interface.

## Tech Stack
* **HTML5:** Semantic document structure.
* **CSS3:** Custom styling, card-based layout, and responsive UI design.
* **JavaScript (ES6):** Dynamic rendering logic, state management, and mathematical calculations.
